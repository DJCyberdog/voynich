## Draft-only experimental delta — EXP-0021 / A-05 (2026-11-10; **not yet integrated**)

**A newly executed, narrowly scoped transcription-level test** asks whether EVA `q`-initial tokens are underrepresented as first tokens of a line, compared with exact random ordering conditional on that line's tokens.
