## Draft-only experimental delta — EXP-0021 / A-05 (2026-11-10; **not yet integrated**)

**A newly executed, narrowly scoped transcription-level test** asks whether EVA \`q\`-initial tokens are underrepresented as first tokens of a line, compared with exact random ordering conditional on that line's tokens. ZL3b-n v3b original-site f3r (exploratory) and before-viewing-selected f8r (limited holdout) were evaluated using standard-library Python. f3r: observed 2 q-first lines / 20, H0 expectation 3.8341, exact one-sided p=0.189378; f8r: 1 / 16, expected 0.2361, p=0.986111. **Neither meets predeclared alpha 0.05; f8r deviates in the opposite direction.** Sensitivities for first-word length and paragraph starts limit the interpretation. This is not evidence that all line-position effects are absent, and not an authentication of original glyphs. The original full-file SHA256 could not be recomputed; manually extracted web lines and their local hashes underlie this pilot. The reproducible script takes an external input, embedding no corpus.
