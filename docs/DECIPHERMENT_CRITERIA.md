# Decipherment acceptance gates
1. Reading: independent transcribers agree on specified folios and uncertainty is encoded; publish reproducible region-to-glyph mappings.
2. Script: compact deterministic or probabilistic mapping rules, independently testable on unseen folios and robust to transcription schemes.
3. Language: converging diagnostics from held-out material, competing languages and nonlanguage null models, without selecting language from illustrative guesses.
4. Semantics: unambiguous, coherent predictions for held-out passages or labels; blind evaluators; independent corroboration rather than post-hoc alignment to images.
5. Historic origin: document and physical evidence separately checked; parchment manufacture is not text-writing date.
Partial success must identify which gate passed. Global decipherment requires reproducible passage-level coverage across distinct sections, independent replication and successful adverse tests. Thresholds and sampling plans must be preregistered before confirmatory tests; no retrospective moving goalposts.
