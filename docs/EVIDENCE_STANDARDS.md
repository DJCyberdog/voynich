# Evidence and operational state
VERIFIED = independently reproduced observation within stated scope; DOCUMENTED = directly visible in identified primary artefact; CLAIMED = sourced assertion not independently re-tested; INFERRED = reproducible reasoning from observations; UNKNOWN = undecidable on available evidence; CONTRADICTED = failed specific prediction in identified test scope. Use ACTIVE/WATCHING/BLOCKED/SATURATED/RETIRED solely for operational status. Record source ID, URL, access date, exact version/checksum when available, locus, transcription layer and transformation chain. No invented numeric confidence. Never promote a secondary-source paraphrase to manuscript observation.
