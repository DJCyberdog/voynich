# Falsification protocol
For each experiment record question, hypothesis, alternatives, immutable references, sampling, held-out areas, preregistered predictions, positive/negative controls, null model, rejection conditions, method, observation, result, limitations and next step. Separate exploratory from confirmatory work. No leakage across exploratory and held-out folios. Report uncertainty, multiplicity, transcription disagreement and sample-length effects. Favour highest discriminating evidence per effort and do not reward PR volume. Repository metadata alone is not an independent manuscript observation.
