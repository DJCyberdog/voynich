## Locked target selection — absolutely no posthoc search
Inspect exactly these folio identifiers **in order**: `f66r` (primary), `f66v`, `f67r`, `f67v` (fallbacks only if earlier folios lack an eligible list). Select the **first** folio with an eligible list; do not pick one because its results look good.
- **Type L0:** numbered IVTFF line-locus with a `[@*+]L0` label, followed by **one standalone, unspaced, unpunctuated editorial symbol** (ASCII lowercase letters or `@NNN;` code). Require **>=12** such entries, ordered by ascending IVTFF line index; no duplicates of line index and no editorial uncertainty markers. If multiple L0 lists, use all in source order.
- **Type Cc:** if no eligible L0 list, a single `+Cc` line with **>=12** period-separated, nonempty standalone symbol units, each matching the same exact symbol alphabet as above. If several, earliest IVTFF line only. Do not reinterpret comma-separated full words as symbols. No line with multiple unseparated tokens may qualify.
- Prioritize eligible L0 over eligible Cc; choose first eligible folio in the fixed order. If all four fail, return **NO_ELIGIBLE_TARGET** and do not score any code hypothesis or silently expand the sample.
- Only folio identifier, source line tags, counts and eligibility flags may be printed before prediction/scoring. Manually read target glyphs **after** the one-shot frozen implementation has written numerical scores.

## Frozen training and prediction (no target fitting)
Build training list A as 68 period-delimited units from `f57v.3,+Cc` and training list B as 26 f49v `[@*]L0` margin labels. Verify counts 68, 26, four `o` starts in A, and corresponding original source SHA. Derive:
1. **R17 rigid transfer:** training template = f57v slots 18..34 (second 17-unit cycle) chosen *before* target; for target list `t[0..N-1]`, forecast `template[j modulo 17]` at EVERY target position, with no target anchor needed. This intentionally severe transfer test of a "universal glyph cycle", not an optimized model.
2. **M5 anchor-conditional transfer:** determine **longest nonoverlapping** pair of near-identical motifs of length 3..8 in the first 14 f49v entries (same first symbol, <=1 disagreement). Fixed tie break: longest, fewest differences, latest second occurrence, latest first occurrence. Use the second occurrence as template. Only *after observing* a target symbol equal to its first symbol, predict the 1..length-1 subsequent target positions, without allowing target-derived parameter changes. The anchor itself never counts. Skip overlapping forecast positions after their first prediction. Report exact **coverage**; no significance claimed for fewer than 8 forecast positions.
3. **Copy-previous baseline:** for every position except the first, forecast previous **observed** target symbol; score exactly the same eligible positions as R17 or M5 as appropriate. This baseline may use prior true symbols, while R17 needs none; state this advantage.
4. **Global-mode baseline:** most frequent unit in combined f57v+f49v training, tie first observed; forecast that constant at every position. No target symbol usage.
5. **Distribution-preserving null:** exactly 10,000 permutations of target units (seed 66013), compare R17/constant template to shuffled target at same indices; compare M5 only conditional on fixed observed anchor indices using 10,000 shuffles (seed 66014). This null is **not** an independently verified historical copying mechanism; the copy-previous baseline is the minimum noncoding comparator.

## Decision rules frozen before target
- Eligibility n>=12. **Positive transfer of R17** requires accuracy >=70% **AND** >=3 more correct symbols than both copy-previous and global mode on the common positions 2..N **AND** one-sided permutation p<=0.05. Otherwise classify `R17_NOT_SUPPORTED`; if no eligible target `NO_ELIGIBLE_TARGET`.
- **Positive transfer of M5** requires >=8 target positions genuinely forecast (not anchors), accuracy >=75%, >=2 hits better than copy-previous on **identical forecast positions**, and conditional-shuffle p<=0.05; else `M5_NOT_SUPPORTED` or `M5_NOT_EVALUABLE` (coverage <8).
- These conditions are necessary signal filters only, **never** proof of code, translation or non-copying origin. Do not apply any Bayesian posterior probability of cipher vs hoax.
- A rigid period may be valid only for **f57v**, so negative transfer does **not** falsify the possibility that the manuscript contains some localized cyclic list or key.
- A code claim would need independent glyph image agreement, explicit reversible mapping, new multi-folio predictions, balanced matched-copy nulls and the five acceptance gates.

## Controls, interpretation, scope
Positive synthetic control: exact copied 17-unit template repeated twice must yield 34/34 R17 matches (if tested); negative synthetic control: a constant unrelated glyph target must NOT trigger the rigid-transfer PASS unless it actually matches template in >=70% of positions. For M5 synthesize two separated exact motifs with known anchors and check correct indexing/forecast coverage; a nonanchor sequence has zero forecasts. All source code Python standard library, no packages installed. On any script/parser error, fail closed without manually editing target glyphs. Changes to logic after target observation require a new protocol and **do not qualify as confirmation** of this freeze.
