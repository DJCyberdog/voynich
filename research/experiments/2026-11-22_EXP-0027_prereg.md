# EXP-0027 — Pre-run protocol (frozen 2026-11-22, before scoring)

## Question and registration status
On the *same previously studied* owner-held ZL3b-n.txt, IVTFF EVA v3b (13 May 2025), does a combined **token-position + immediate previous-token context** model predict a token's combined `(begins with EVA q, final-letter class)` on distinct folio-number roots better than either factor alone, **after controlling Currier metadata, token length and line length**? Tests scoped A-01/A-05/A-13 and prior EXP-0018/0025/0026; no particular language, cipher, copying mechanism or semantic decoding is predicted. This is **exploratory in a previously exposed single witness**, not a sealed independent heldout nor a new decipherment gate.

Source is Owner Library ZL3b-n v3b, 411,671 bytes, SHA-256 `bf5b6d4ac1e3a51b1847a9c388318d609020441ccd56984c901c32b09beccafc`, header `#=IVTFF Eva- 2.0 M 5`. Manifest SRC-0007 is separately Owner-canonical but not independently live Yale authenticated; no physical-image concordance or permissions inferred. Input corpus is read locally but not copied into GitHub.

## Fixed inclusion/split (no result inspection before protocol)
- Parse lines `<fNr[optional fold suffix].line,+P0>` or `<fNv[...].line,+P0>` by regular expression with `+P0` exactly; remove `<!...>` comments and known `<->`/`<~>` into periods; strip other XML-like angle tags, then **require every dot-delimited token** to match `[a-z]+` and at least 3 accepted tokens, otherwise exclude entire line. This *intentionally excludes comma-uncertain* words, annotations, braces, alternative glyphs and other non-EVA tokens, rather than silently resolving them.
- Folio-root group is `f` plus integer, shared across r/v and fold parts: a proxy for physical grouping only, NOT authenticated physical leaf identity. Exclude roots `f3` and `f8` seen in earlier pilots. Holdout is deterministic 5-fold SHA-256 of ASCII `EXP0027-root-v1|` + root (first 8 bytes mod 5); train on four folds, score fifth, repeat. This is *out-of-root prediction on an already exposed editorial witness*, not unseen evidence.
- Currier `$L=A/B` from matching folio header, else U. Token word-length bins: <=3, 4–6, >=7; line-length bins: <=4, 5–8, >=9; position FIRST, INTERIOR, LAST; predecessor class START for first token, else previous observed class (teacher forcing, not free generation).
- Target: 8 states = EVA first-character `q` yes/no × ending letter `y`, `n`, `l`, or OTHER. No glyph, morphology, etymology, translation or semantics interpretation.
- Predictive model B0: global smoothed class distribution (add 0.5 per state); Currier-specific distribution shrunk to global with strength 25; baseline `(Currier,length-bin,line-length-bin)` class count shrunk to Currier distribution with strength 25. P: add token position and shrink to B0 (strength 25). C: add previous target class (or START) and shrink to B0 (strength 25). H: add both factors and shrink to equal mixture of P and C (strength 25). All feature counts/backs-offs fitted strictly to training roots of each fold. No tuning on scored roots.
- Primary criterion: aggregate teacher-forced negative-log-likelihood (nats/token). `D=minimum(loss(P),loss(C))-loss(H)`; positive implies complementary predictive information, negative implies single-factor model preferable. **Prespecified practical threshold** D >= 0.005 nats/token, D positive separately in Currier A and B groups, and shuffled-null empirical upper-tail p <= .05. If any fail, do NOT claim distinctive complementarity. Other contrasts descriptive. No language-vs-cipher-vs-copy identification from this test.
- Null: 99 deterministic-seed within-line **within-token-length-bin** class permutations preserving each line's counts by word-length bin (and folio/Currier composition), while breaking much previous-class and positional association. For each permutation refit 5-fold models. One-sided empirical p=(1+#null D >= observed D)/100. Report null distribution, its limitations from short/unswappable groups and confounding.
- Positive synthetic control: replace source target classes using deterministic generator with dependence on both previous class and position (and fixed seed), with same line and root skeleton; record whether H beats P and C; it tests software signal detection, not real manuscript validity.
- Negative synthetic control: substitute independently sampled classes at each position from training-independent global uniform 8 states (same skeleton, fixed seed); do not require negative D exactly zero, but assess absence of systematic >.005 gains.
- Cluster uncertainty: 2,000 fixed-seed bootstrap resamples of root-level scoring contributions, report descriptive 95% percentile interval for D; no inferential physical-leaf independence assumed. Report folds, per-Currier groups A/B/U, exclusions, target prevalence, and predefined predictive losses.
- Controls and result statistics will be computed by a *new* self-contained, Python-standard-library-only reproducible script. Fail closed if source bytes or header do not match. Code/results/report are created only after this preregistration is committed.

## Strong alternatives and rejection scope
A natural-language morphological/orthographic process, structured cipher with position-dependent tokens, template-driven nonlinguistic copy/edit generator, and mixed systems can ALL yield combined dependence. More stringent nulls should preserve line composition, section, hand and physical leaf; some cannot be verified in this single-source test. A success rejects only the tested weak conditional independence/shuffle explanation for this editorial source. Failure to improve falsifies the **particular combined predictor under these frozen choices**, not every hybrid process. No semantic, decipherment, manuscript dating or origin claim.
