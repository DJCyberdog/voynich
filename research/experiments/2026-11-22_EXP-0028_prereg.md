## Single decision question
At equal five-fold folio-name-root split and identically scored exact word strings, **does a generative one-edit copying channel with resets** explain the next EVA token better than the same underlying character-bigram model alone? Is a position-dependent copying rate needed beyond a global copying rate? **All model families share the same fitted character-bigram innovation base**, so improvements isolate the *incremental* contribution of mechanical local copying rather than suggesting that an ordinary language, a cipher, or gibberish has been identified. Additionally, prove/test a *bijective fixed monoalphabetic substitution* model is observationally equivalent to its character-bigram latent model under relabeling. The latter is a non-identifiability control, NOT evidence against all ciphers.

## Fixed data, folds, scoring
- Source hash and header fail closed. Same strict EXP-0027 `+P0` parsing: `<fNr/v[optional panel].line,+P0>` with at least 3 period-delimited tokens wholly matching `[a-z]+`, remove `<!...>` comments and markup, conservatively reject commas/uncertainties, exclude f3/f8. Group all sides/panels under `fN` numeric root (not independently authenticated physical leaf). Dataset skeleton should reproduce EXP-0027's **1,537 lines, 12,167 tokens and 94 roots** or fail. Use same fixed five-fold `sha256('EXP0027-root-v1|'+root).first8 % 5` as EXP-0027: exposed out-of-root folds, not new sealed evidence.
- Train character-bigram model `B(w)` from training-only words with alphabet `a-z` plus END symbol; start symbol `^`, additive alpha 0.5 for each possible next letter or END, including normalization of word termination. `B(w)` is normalized over finite nonempty lowercase strings conditional on generating a first letter (at start do not generate END); at interior characters allow END. Report entire word log probability, measured **nats/token** not per-character. No train/test word leakage through fitted emissions.
- From preceding *observed* token in same line (teacher forcing), one-edit kernel `E(w | previous)`: EXACT 0.25; one-character SUBSTITUTION 0.40 uniformly over positions and 25 other letters; INSERTION 0.20 uniformly over slots and 26 lowercase letters; DELETION 0.15 uniformly over positions, only if previous length>=2. For previous length 1, renormalize valid operations by their total 0.85. Count all edit paths giving identical output. A true probability distribution; independently unit-test normalization on a short artificial previous token. At first token of line E unavailable and all models use B.
- **L language-like** generator: independent word innovation from B. **K cipher-like**: replace all symbols of the data by fixed ROT13, fit the same B on rotated TRAIN and evaluate rotated TEST. This has exactly the same number of parameters and is *provably observationally equivalent*, not an independent cipher discovery. **M mechanical-copy** generator: at non-first tokens choose E with globally trained rate lambda and B otherwise; **H contextual hybrid**: choose E with separate INTERIOR or LAST token rates; first uses B. All models can generate arbitrary valid lowercase token sequences via B resets, with the same learned B backbone; M adds one fitted scalar and H adds two, using the same training data and 0.5 smoothing. Lambda is optimized from training-only mixture likelihood via fixed 60-iteration golden-section maximization over closed [0,0.8], no tuning against heldout.
- Use identical 5-fold root grouping, teacher-forced within-line prior token, same scoring denominator for all four models. Negative log likelihood is exact word log probability. Primary `gain_M = NLL_L - NLL_M`; confirmation requires pooled gain >= **0.01 nats/token**, positive gain in Currier A and B scored strata, and `p <= .05` under **49 seed-fixed within-line word-position shuffles** (shuffle words within exact word-length buckets, preserving each line's token inventory, positions-by-length, source metadata). Secondary `gain_H = NLL_M - NLL_H`; improvement only if >=0.005 pooled and positive in A and B, otherwise NOT_MET. All other contrasts report descriptively.
- Permutation null: 49 seeds `282800+i`, refit all five folds, shuffle in-line words only within same **exact** character length, preserving line multiset and per-position lengths. Breaks some adjacency, but can preserve many same-length repetitions; explicitly report how many tokens are movable/changed. Empirical one-sided p=(1+number null gains >= observed)/(50).
- Synthetic positive control: deterministic seed 282801; for each non-first token independently 30% chance replace by exact previous word (and for half these events by exactly one random substitution), to create reproducible local copying signal; expect `gain_M>0.01` on same split. Negative control: seed 282802 global shuffle of words **within Currier metadata group** across accepted lines, leaving line/root/metadata skeleton intact; expect `gain_M <= +0.01` (not necessarily <=0). Neither synthetic control is manuscript evidence.
- For real-data uncertainty: 2,000 seeded root-bootstrap percentile draws for `gain_M` and `gain_H`; these are **descriptive**, no physical leaf or independent transcription interpretation. Report fold counts, Currier A/B/U, acceptance exclusions, fitted lambda distributions, mean/max edit-probability hits, null range and synthetic controls. All train-only fitting and strict dataset cardinality assertions in first-party Python-stdlib script, no third-party packages.
- Source-level "positive" is **not** evidence for natural language, a meaningful cipher or a real copyist: many generators can mimic local copying, including spellings, scribal conventions, ciphers and hybrids. Strongest alternative is a linguistically meaningful but local-repetition-rich morphology or a procedural text producer using a *different* edit repertoire (more than 1 edit), plus page/section/hand mixing. Falsify only these exact emission models and null, not entire families. Potential failure on unseen independent witness, line-specific frequency, section and physical leaf is kept UNKNOWN. Five decipherment gates remain 0/5.
