## Data and pre-fixed methods
Exact EXP-0027 conservative strict `+P0` / certain ASCII `[a-z]+` parser, reject ambiguous comma/markup/short lines, f3/f8 pilot roots excluded. Source 5,225 text rows: 1,618 non-`+P0`, 63 prior f3/f8, 2,007 short/uncertain after other filters. Analyzed **1,537 lines / 12,167 tokens / 94 folio-name roots**. Reuse EXP-0027's SHA-256 5-fold root split; scored 16/16/17/19/26 roots (2,286/2,705/2,159/1,906/3,111 tokens). These are not independently authenticated physical leaves and this corpus has been previously analyzed.

All models generate complete word strings and are scored in **nats per word/token**, with a fixed training-only character-bigram word-innovation baseline `B(w)` (26 ASCII letters, START+END, add-0.5). All words are scored on exactly the same five held-out-root folds.
- **L** — purely independent character-bigram word innovation, "language-like" *surface model*, not actual linguistic grammar.
- **K** — fixed ROT13 reversible substitution of a separately trained, correspondingly transformed L. A bijective symbol relabeling mathematically has **identical** surface likelihood and parameter count. K is a non-identifiability control, NOT a representative homophonic or polyalphabetic cipher.
- **M** — mechanical **single-edit copy channel** with training-fitted one global mixing rate lambda, reset innovations from **the same B**. Channel outcomes: exact previous word 0.25; uniform one substitution 0.40; one insertion 0.20; one deletion 0.15 (renormalize if deletion impossible); count duplicate output paths. Each next token is scored conditional on *observed* previous token (teacher forcing). This is **one extra free scalar** relative to L.
- **H** — same exact innovations and edit channel, but separate trained INTERIOR and LAST copying rates (**two** extra scalars instead of one). Both M and H can also be interpreted as locally repetitive natural-language or cipher-compatible models, so generator ontology remains open.

Training-only rates fitted by fixed 60-iteration golden search with bounds [0,0.8]. Independent enumeration on previous words `a`, `ab`, `aa` verified **edit probability normalization PASS**. Original manuscript image, shape/ligatures, lexical semantics, spelling validity, Currier attribution correctness and alternate transcription untested.

## Falsification, strong rivals and evidence states
- **VERIFIED (bounded):** source byte identity, parse/exclusion counts, code edit-kernel normalization, CV log losses, synthetic controls, exact ROT13 reparameterization, and fixed permutation/bootstrap results from the one named editorial EVA file.
- **CONTRADICTED (bounded):** the proposition that this exact independent char-bigram generator is as predictive as the same generator with a trained local one-edit copying component *under the frozen criterion and null*. **NOT** contradicted: natural language, meaningful code, abbreviations, homophonic cipher, alternate copy algorithm, hybrid script or editor bias.
- **INFERRED:** within this already exposed editorial representation, a **small but measurable one-edit local-dependence signal** improves prediction. Context-specific edit rate does not clear the fixed threshold. Fixed monoalphabetic cipher and latent language-like model are unidentifiable from surface character relabeling alone.
- **UNKNOWN:** whether patterns survive different independent EVA/IVTFF transcribers, manuscript glyph-level alignment, physical leaves/hand/section, a stronger context-conditional natural-language model, richer copying or encrypted-generator alternatives, and genuine unseen holdout. Evidence from A-01/A-05/A-13 remains entangled; no distinct hypothesis proven, semantic gate passed or A/W item closed.

**Strongest counterhypothesis:** ordinary natural-language morphology or procedural/cryptographic word selection with repeated local forms, plus Currier/hand/section mixtures, can cause the same edit-neighborhood likelihood improvement. A more sophisticated language process, stateful encryption, or copy generator could reverse model ordering. The M vs L baseline shares a word-innovation process to control parameters and testing, but does not constitute four independent faithful competing hypotheses. **The current result determines only a first tractable model distinction.**
