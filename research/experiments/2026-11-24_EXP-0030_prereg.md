## Frozen data and models
Exact EXP-0029 parser (P0, angle tags to dots, complete [a-z]{4,} segments), same COMPOUND greedy longest-match units cph/cfh/ckh/cth/ch/sh, otherwise ASCII. Use same EXP0029-root-v1 hash modulo 5 split for comparable train/test (previously exposed). No hand/section labels used, no claim of physical glyph equality. At each word position collect joint immediate neighbor context (left,right), including ^/$ boundaries. Train eligible units >=100 occurrences. For every eligible unordered pair compute raw joint-context cosine on TRAIN only. Derive disjoint pairs by greedy descending cosine (lexicographic tie), only cosine>=.85, maximum five pairs. No manually selected pairs. TEST scores: cosine on independently computed heldout count vectors; full-word frame overlap Jaccard, where frame is tuple of remaining compound units with one masked slot (same position/length), counts converted to presence/absence, for each unit across TEST words. Frame overlap measures attested alternative fillings, not meaning or permission to substitute arbitrarily. Report token support, distinct frames, intersection, train/test cosine, Jaccard. For each learned pair require both TEST counts >=20 and >=10 distinct frames each; otherwise report pair insufficient and global INCONCLUSIVE, no removal.

## Frequency control and decision
For each learned pair build control pool from all other unordered eligible TRAIN pairs except ALL learned pairs; rank by Euclidean distance between sorted log TRAIN occurrence counts of target and candidate. Take nearest 10 pairs (ties lexicographic); no TEST-informed matching. Report maximum log-count mismatch and actual control pool. Evaluate TEST metrics for controls without dropping rare/zero units: if no vector or no frames define cosine/Jaccard=0. Primary global statistic = arithmetic mean of learned-pair TEST Jaccards; secondary mean TEST cosine. Null = 999 seed-300030 draws sampling independently one pair per matched pool with replacement, mean Jaccard (also report cosine descriptive). This is a conditional matched reference distribution, not an exact exchangeability test; overlap among pairs and imperfect frequency matching limit inference. Report one-sided empirical p=(1+#null>=observed)/1000. Primary success requires >=3 learned pairs, all support gates, observed mean Jaccard at least .02 above null mean, empirical p<=.05, and mean heldout cosine>=.70. No per-pair confirmatory significance; pair metrics descriptive only, no multiple testing by selecting favorable pairs. Report 400 paired-root bootstrap draws seed 300031 for mean Jaccard difference between learned and fixed mean of each control pool (resampling TEST roots, rebuilding presence sets); descriptive percentile indices 9,389, not primary gate. No retuning. If valid gates fail NOT_MET; if support fails INCONCLUSIVE.
Positive control: synthetic training/test pairs a/b have identical 20 distinct full-word frames, c/d disjoint frames, same frequency each, assert learned a/b Jaccard=1, c/d=0, cosine a/b=1. Negative: equal frequency e/f disjoint frames and distinct neighbor contexts, Jaccard=0 cosine=0. Synthetic control validates metric implementation, not real manuscript mechanism.

Strongest alternative: ordinary phonotactics, scribal slot restrictions, copy/edit, cipher or mixed production can generate similar contexts/frames without same function; frequency and word-boundary structure may confound. No semantic, phonetic, allograph or decipherment claim. Report any result and code, no raw word frames in repository.
