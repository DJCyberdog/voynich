## Question
Do the five fixed EXP-0030 pairs ch/sh, k/t, f/p, l/r, cph/cth have distinct external word contexts even within identical masked target word frames, folio-number root and coarse line position? H1: training-derived context score ranks variant B above A within TEST matched strata better than chance. H0: exchangeability of variants within matched strata conditional on counts. Strongest competing causes: local copy/edit, scribal/section microstructure, discourse/topic, orthography, cipher or hybrid rather than semantic/morphological function. A positive result identifies distributional discrimination only; failure does not establish equivalence.

## Fixed parsing and features

Replace every angle tag by '.!.' to prevent adjacency across markup (including <-> and <~>); split dots, retain empty/invalid pieces as barriers, never bridge across line/uncertain gaps. Eligible target full [a-z]{4,}; both immediate neighboring pieces must be nonempty full [a-z]+ (may be short); require one and only one occurrence of either unit of a given pair in target; different pairs may contribute rows from same token. Greedy longest compound segmentation cph/cfh/ckh/cth/ch/sh else ASCII. Mask the single pair unit, yielding exact tuple frame. Coarse line-position stratum early if 2*raw segment index < number of raw segments, otherwise late (editorial proxy). Matched stratum key (pair, folio root, frame, early/late); count only strata with both labels in TRAIN or TEST separately. Folio roots are not certified physical leaves. Same root never split across train/test. Features of each immediate neighbor: direction-specific first and final compound unit, compound-length bin 1,2,3,4,5+; six categorical features per row. No target features in context score. 
For each pair and mixed TRAIN stratum g, let p_g=mean B label. For each feature value f accumulate numerator sum of (y-p_g) over rows bearing f and denominator count of rows bearing f, across mixed TRAIN strata. Weight w_f=numerator/(10+denominator), unseen features 0. Score s=sum six weights; no tuning. TEST evaluation only on mixed strata. Cross-label comparisons within each stratum, win if score_B>score_A, half if tie. Primary AUC=sum wins / sum comparisons over all strata and pairs. Conditional label-permutation reference: 999 draws seed 310031 independently shuffle scores relative to fixed labels within each matched TEST stratum (same counts/scores), compute AUC, one-sided p=(1+exceedances)/1000. This is a conditional model null, not proof of independence across nearby words or pairs; same token may enter multiple pair tests.
