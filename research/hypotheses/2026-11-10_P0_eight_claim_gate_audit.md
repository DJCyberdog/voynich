### Preregistered source-level prediction and falsification rule

Before inspecting the eight metadata headers, fix the page list:
`f5v, f24v, f29r, f43r, f57r, f76v, f104v, f113v`.
Test *only* whether the recorded IVTFF variable `$H` (Davis hand) is semantically the same field as `$C` (Currier hand) and whether **within these eight editorial labels** both A and B occur for a fixed `$H`. If a page has different nonmissing `$H`/`$C`, the assumption of their literal identity is falsified for the source metadata. If each present `$H` stratum has only A or only B, language and hand are **not separately identifiable from these eight metadata records**; this does NOT establish full-corpus confounding or disprove separate scribes/languages. No statistical significance is claimed for convenience sampling.

**Authoritative original format specification:** René Zandbergen, *IVTFF – Intermediate Voynich MS Transliteration File Format*, version 2.0.1, document issue 2.0.2, 2025-07-08, section 6.3 / Table 6, https://www.voynich.nu/software/ivtt/IVTFF_format.pdf . Explicit semantics: `$L` Currier A/B language; `$H` hand attribution **according to Lisa Fagin Davis**; `$C` **Currier's hand classification**. These are three distinct editorial variables; none is an independent manuscript-visible physical observation. Source transcription: René Zandbergen/Gabriel Landini, `ZL3b-n.txt`, IVTFF Eva-2.0 M5, v3b 2025-05-13, https://www.voynich.nu/data/ZL3b-n.txt . A/B refers to **statistical transcript regimes**, not two proven natural languages. **Falsifiable strong prediction:** on independently labeled, previously unseen folios in covariate-overlapping hand/section/layout strata, text features yield additional predeclared heldout A/B predictive information beyond these covariates. **Best counter:** hand, section, text convention and layout fully explain editorial A/B partition. **Positive:** seeded synthetic extra text-regime signal with known label. **Negative:** matched page-label shuffle *within jointly populated strata*. **Null:** no heldout improvement over hand+section+layout only, under a fixed model complexity budget. **Holdout:** folios/bifolios not used to select features/labels. **Actual outcome:** 8-header metadata cross-tab shows no within-$H A/B overlap **in this sample** and forbids pretending the eight headers identify a separate A/B effect. **UNKNOWN** for genuine whole-corpus independent A/B mechanism; need a full folio-level stratum feasibility table before a statistical test.
