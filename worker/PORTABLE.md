# VRS 0.13.0 portable development candidate

Source only; not an accepted self-installing distribution. Native assets and qualification are pending.

1. Obtain a trusted full Windows x64 CPython 3.13 ZIP with python.exe at its root, Tcl/Tk, venv and ensurepip. The official minimal embeddable ZIP alone is insufficient. Verify provenance, publisher and independently trusted SHA-256; unpack into a clean local bootstrap/ directory. No global Python required by launchers. No certified bootstrap included; do not execute untrusted assets.
2. Run Probe.bat before large downloads. Auto conservatively chooses review. CPU/CUDA require explicit selection; CUDA requires driver and actual smoke test. Existing profile never silently changed.
3. Obtain a complete Windows CPython 3.13 x64-compatible wheelhouse, including transitive dependencies and optional tray dependencies, matching requirements-review.txt, requirements-compute.txt and the chosen backend. Independently verify origins, hashes, ABI and licenses. Review must exclude Torch, NumPy and PyMuPDF.
4. Prepare.bat review python-runtime.zip wheels-review (or cpu/cuda) stages bytes by hash and emits a NOT_APPROVED plan path and hash. After reviewing it: Setup.bat --profile review --plan config/install-review.json --approve <reviewed SHA256>. Offline default. Online mode accepts only individually pinned approved HTTPS assets; offline plans have empty URLs. Hash generation is not independent verification.
5. Start.bat opens desktop in foreground; Stop.bat requests cooperative managed worker stop and waits for confirmation. Close GUI separately before maintenance. Repair.bat rebuilds from recorded plan and cache after relocation; Update.bat --profile ... --plan ... --approve ... updates the same profile dependencies; for source-only updates see below. Retained interrupted backups require explicit recovery.
6. Diagnostics.bat writes bounded redacted technical JSONL ZIP under logs/diagnostics. VRS.bat logs prints recent structured events. GUI Log Viewer offers level/module/search and local export. config/logging.json schema 1, level TRACE/DEBUG/INFO/WARNING/ERROR/CRITICAL, days 1–90; default INFO/14 days. No raw exception messages or scientific evidence.
7. VRS.bat secret-set --slot VRS_GITHUB_TOKEN_EXAMPLE prompts without echo using Windows user-scope DPAPI. VRS.bat repository --slot VRS_GITHUB_TOKEN_EXAMPLE -- check PROFILE invokes the local CLI with selected credentials only. Account-bound ciphertext may require reprovisioning after host/account change. Never distribute config/secrets or live workspace.
8. Build.bat builds deterministic source-only ZIP against portable_sources.json from clean source. No runtime, wheelhouse, private research input or workspace included.

Native installation, DPAPI, full GUI/worker/tray, actual source ZIP build, complete lock/license provenance, clean relocation/resume/delete, all external write checks and full regression remain open. No admin/global registration intended; OS/driver traces, unmanaged direct entry points and external publications outside wrapper scope. No secure erasure or general sandbox. Native source-update acceptance, comprehensive inner-stage logging and general artifact quotas remain unfinished. Do not use production data until acceptance.

## Disposable qualification (developer only)

On trusted Windows x64 CPython 3.13 with Tcl/Tk, venv and ensurepip, run from worker/: `python -B vrs_native_acceptance.py --profile review --disposable-test --report native-review.json` (or cpu; cuda only on an appropriate NVIDIA device). This explicitly permits candidate dependency resolution/downloads in a disposable directory and test-only installation, not installation of production data. Results include candidate hashes and individual checks. Do not copy the test approval to an owner installation. Full source and dependency licensing review is required before distributing any binary bundle. See [native acceptance checklist](VRS-132-134.md).

## Explicit source-only update

With all desktop and worker processes stopped, use `Update.bat --source "path-to-approved-source.zip" --approve SHA256` for a compatible complete source ZIP produced by the builder. Independently verify the package origin and review the exact SHA-256. The updater refuses local source edits, unlisted files, private paths, collisions and changes to launchers, dependencies or recovery-critical code. Those require a separate full-package migration. A local journal and backup protect the managed source files; `Update.bat --recover-source` explicitly rolls back an interrupted transaction. Normal exclusive launches are blocked while recovery is pending. The updater clears designated generated bytecode caches only; config, runtime, models, data, research evidence and workspace state are not migrated. A changed scientific worker identity may prevent existing runs resuming; keep the prior package and complete or explicitly migrate affected runs before update. No automatic download, signature trust or power-loss guarantee. Native validation remains pending.

## Component and license review inventory

From a trusted local bootstrap: `bootstrap\python.exe -E -s -B vrs_license_inventory.py review --plan config/install-review.json --approve SHA256` (select the installed profile and exact reviewed plan hash). The report is stored under workspace/distribution and binds to the existing source manifest and verified cached assets. It contains wheel identities, dependency declarations, license metadata, notice hashes, runtime embedded-wheel paths and missing-data flags. This is an inventory for human review, not a formal complete SBOM or redistribution approval. Review embedded/native/vendor components, source/asset rights, notice obligations and publisher provenance before distributing a package. Keep the original verified bytes for the reviewer. CI reports are disposable candidate evidence only.

### 0.13.x qualification and keyboard navigation

Keyboard shortcuts: Ctrl+1 Home, Ctrl+2 Review, Ctrl+3 Sources, Ctrl+4 Jobs, Ctrl+5 Evidence, Ctrl+6 Settings, Ctrl+7 Logs. Ctrl+J and Ctrl+E remain available. On the Home run list, Enter opens the selected review. Tab/Shift+Tab move focus. Tray exit waits for the current UI task to finish; it does not stop the independent worker. Stop the worker explicitly before maintenance.

Repeat with cpu and cuda as appropriate. This downloads disposable test candidate dependencies; it never approves a release lock or installs globally. The generated report records measured UI and classifier evidence. Do not treat hosted administrator CI as a non-admin owner test. No existing VRS workspace is used. Check actual tray icon/menu show/hide/review/exit and visible synthetic notification in the Windows notification area; Windows notification policy may suppress it.
