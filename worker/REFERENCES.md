# v0.5.1 reference-catalog integration (work in progress)

The local importer accepts a SHA-256-pinned PDF, discovers table-cell candidates, and creates source-attributed clips. It distinguishes unreviewed preview from explicitly reviewed private catalogs. The owner-supplied STA1_def.pdf v1.03 (2025-09-13), SHA-256 85a595aa61936fa103a0f2c11d980e9970e11f98d1f35038f9fc268cc433ada2, was actually processed. 286 STA1, 180 STA1R, 234 EVA-from-STA, and 184 v101-from-STA labels were loaded, 1126 reference records in total. The pictures for STA entries are taken from the corresponding EVA/v101 image columns, not a separate STA font. Five standalone labels have no individual visual cells: B7, B8, E3, F5, G4. Combination rows and non-script/placeholder families Y/Z are excluded. These are partial inventories, not independently verified. No images or source PDFs belong in Git. The original EVA reference PDF and additional conventions are still outstanding; the EVA discovery branch has not been validated on the actual EVA document.

Example: `python reference_import.py discover STA1_def.pdf <sha256> sta plan.json`, then `python reference_import.py build STA1_def.pdf plan.json private-catalog --preview`. Use `active_review.py` with the resulting `references.json`. An approved build without `--preview` requires explicit plan review and private-use confirmation. The UI shows the coverage qualifier. Do not interpret absence in a partial catalog as absence from the transcription system.

Similar uncertainty candidates are ordered by a fixed binary-image similarity heuristic. Each is reviewed individually; there is no automatic propagation. Up to 12 catalogs and 1024 labels per review catalog are supported. The glyph classifier itself remains limited to 256 classes. Tests: 36/36 Linux CPU/Xvfb, including 3 new importer/grouping tests. Real STA preview loaded successfully; not a scientific accuracy test. No Windows or CUDA test.

## EVA2 original and historical comparisons (2026-11-25)

The owner-supplied EVA2 reference (updated July 2004, SHA-256 `2f9a9c7e81dedfbd934e49eeac47de07e7e0855eda46f063a0624958d3e524fc`) was actually processed by `eva_import.py`. It checks the pinned edition, table layout and the EVA2 font in every visual source cell. Page 1 contributes 26 basic and 11 capitalized connectivity forms; page 2 contributes 85 extended codes, retaining source `&number;` notation rather than silently changing to STA's `@number;`. Page 4 and pages 6–7 contribute connectivity and historical comparison examples. The 147 distinct EVA reference labels include sequences and variants, not 147 independently established physical glyphs. Bennett (24), FSG (36), Currier (36), Frogguy (43) are historical comparison views based on EVA-rendered source cells, not complete native alphabets. Italic combinations are labeled as non-original combinations; footnoted Currier n and FSG 6/7 are omitted. Blank cells and transcription markers are not mapped. Four doodles and ten Dee-like numerals are in a separate auxiliary catalog. The source's copyright notice is retained in provenance; no font files are extracted or distributed.

Private use: `python eva_import.py discover eva2_reference.pdf eva-plan.json`, `python reference_import.py build eva2_reference.pdf eva-plan.json eva-catalog --preview`, then `python eva_import.py combine combined sta-catalog/references.json eva-catalog/references.json`. Load `combined/references.json` in `active_review.py`; `combined/auxiliary.json` is optional and separate. No automatic alias conversion, retraining, or cross-convention glyph identity assertion. The nine primary views include both the 2004 EVA source and the later EVA/v101 columns from STA v1.03. The `aaa` inventory is not in these sources and is still open. Reviewable image previews are source-derived, not independently verified or exhaustive. Never infer a novel glyph from absence alone.

Test command: `EVA_REFERENCE_PDF=/path/to/eva2_reference.pdf xvfb-run -a python -m unittest -v test_worker test_pipeline test_gui test_bridge test_regions test_glyphs test_glyph_review test_active_review test_reference_import test_eva_import`. 39/39 PASS on Linux CPU/Xvfb, including actual EVA PDF discovery, rendering all 329 reference records and catalog validation, plus prior tests. Windows/CUDA and scientific manuscript validation remain open. No source PDF, generated reference image, or font is to be committed.
