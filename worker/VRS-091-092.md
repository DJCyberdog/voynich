## v0.9.2 — versioned local scope contract

Implemented `vrs_contract.py` as a dependency-light, offline contract library. Version 1 permits only module `voynich-manuscript` and protocol `fixed-manuscript-v1`. A locally configured run does not need a remote job or experiment ID. Fixed stages: script regions, glyph segmentation, glyph classification, exception review and transcription alignment. No arbitrary action, command, hypothesis, autonomous research, automatic training or scope expansion.

Manifest fields: schema, module, protocol, inputs (exact manuscript/groups/references/model/recognition_policy artifact references), transcriptions (one to twelve artifact references), backend, seed, run_nonce (32 lowercase hex, generated and persisted by future coordinator). Each artifact reference is a relative POSIX workspace path and SHA-256. Canonical JSON hashing binds the run, including replica nonce. Input contents, paths and stage outputs are locally checked; traversal, symlinks, alias paths, tampered digests, duplicate JSON keys, unknown fields/schema versions and oversized JSON are rejected. Legacy files are preserved; no automatic migration or rewrite.

Stage receipts bind schema, run_id, stage, state, reason, artifact and counts. Fixed dependency order for a single run. A pending review may block dependent alignment; unrelated processing across runs is a future coordinator feature. Counts conserve classification total = accepted + abstained + failed and abstained = resolved + pending + deferred. Accepted is a producer-supplied count under the separately validated recognition policy; this contract does not calibrate scores, verify classifier truth or prove actual backend execution. The trusted local producer must measure counts and backend, not fabricate them. Receipt checks bind artifact bytes, not semantic correctness. No hostile concurrent filesystem mutation security guarantee.

Evidence is deterministic, allowlist-scoped and contains repository, research commit, worker digest, actual backend, seed, input hashes, per-stage states and receipt/artifact hashes, aggregate counts and distinct technical/scientific status. Scientific status is always UNADJUDICATED. No private paths, images, source bytes, labels, arbitrary text or credentials exported. `verify_evidence` rebuilds from local pinned inputs/receipts and rejects changes. No network calls, publication, or automatic pipeline scheduling are implemented by this contract. Existing optional legacy bridge is unchanged; future coordinator and reporting integration must use this contract and enforce local authorization, output consent and exact report verification. Live GitHub reporting remains untested and is a later gate.

11 tests cover stable evidence, no remote job prerequisite, abstentions/deferred cases, failure state, schema/scope rejection, input/output tamper and binding, path/symlink/alias rejection, numeric consistency, destination/backend isolation, report manipulation, bounded JSON parsing and separate replica identity.
