# VRS-093 — durable local ledger and outbox

2026-11-25. Parent: 9a861af677ed3e809a90489fd406d7fd994a38fa (PR #94). Local technical acceptance PASS for the ledger API, not yet a running background worker.

## Implementation

- SQLite schema 1, local trusted disk, BEGIN IMMEDIATE, FULL synchronous, transactions and rollback. One database per local workspace; do not use a shared network filesystem. Fixed-scope manifest, actual backend and worker digest are bound on registration. No new job scope or remote commands.
- Durable stages, immutable artifact digests, checkpoint pointers and append-only receipt/checkpoint history at the API level. Token-based exclusive claims and generation-fenced explicit recovery after confirming the previous worker/publisher has stopped. Cooperative pause/cancel requests require the future worker to poll and acknowledge; no hard kill, no automatic stale-token timeout. Resume checks current inputs/receipts; actual stage-specific checkpoint decoding and automatic resume are future integration. Independent local runs can be claimed while another run is blocked for review. Stage dependencies and aggregate denominators are validated, not inferred.
- Outbox snapshots are canonical evidence from v0.9.2, deduplicated by report SHA-256, with separate PENDING/SENDING/SENT states. Publication consent and repository allowlist are checked at enqueue and claim. Failed delivery can return to PENDING without rerunning compute; a future transport must reconcile remote PRs before retry and validate exact remote bytes. Receipt schema binds repo, report hash, PR number and commit; this version does not authenticate remote receipts. Partial blocked/failed reports and completed reports are supported; paused/cancelled/active runs are not enqueued under current evidence schema. No network, GitHub writes, automatic scheduler, scientific work, or actual manuscript-stage execution is performed by this module. Local DB is not a security boundary against malicious writers, concurrent file tampering or a live worker incorrectly declared stopped; historical artifact files must remain immutable.
- Stage checkpoints and blocked review receipts use new immutable paths for changed bytes. No automatic model promotion, training, or independent hypothesis generation. Future coordinator uses these interfaces within fixed manuscript scope; no GitHub job prerequisite.
