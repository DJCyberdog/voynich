## Development CLI

Use from worker/ with the existing Python compute environment, ROOT an existing local app/workspace directory. All manifest refs and plans use root-relative paths and verified SHA-256. Plans contain schema 1 and manifests array of {path,sha256} references to fixed VRS-092 manifests. Example commands:
- python vrs_service.py ROOT register config/run.json
- python vrs_service.py ROOT register-plan config/local-plan.json
- python vrs_service.py ROOT watch --plan config/local-plan.json --interval 5
- python vrs_service.py ROOT once / list
- python vrs_service.py ROOT status RUN_ID / queue RUN_ID
- python vrs_service.py ROOT pause RUN_ID / resume RUN_ID / cancel RUN_ID
- python vrs_service.py ROOT recover RUN_ID GENERATION --confirm-stopped

The watch process is explicitly started locally, not an installed OS service. On Linux SIGINT/SIGTERM request cooperative stop. Windows signal/lock behavior requires native verification. Do not use the historical alpha.1 CLI or low-level Ledger.resume to override new dependency controls. All managed state under workspace/vrs095. Setup.bat and portable environment/cache/deletion acceptance are VRS-130.
