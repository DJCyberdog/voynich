## Implemented

- Real CPU scoring using the original glyphs.feature/classify implementation, unchanged glyphs.py and alignment.py. Separate model and alphabet provenance per convention; no implicit EVA/STA1 cross-conversion. Bounded 64-item inference batches, per-page checkpoints with source/hash and denominator validation; no automatic fallback, training or threshold adjustment. Immutable OCCURRENCE_OUTCOMES_V2 adds raw per-model top label, distance and margin. V1 queue inputs remain supported for legacy fixtures. Scores are not probabilities. Errors in inference/integrity pause the stage rather than fabricate a completed denominator; this version has no isolated per-candidate runtime-error recovery.
- Default no approval: every candidate abstains. Missing model, outside legacy distance threshold, insufficient margin and uncertified geometry remain distinct reasons. Optional automatic acceptance is strictly local opt-in: pinned approval SHA-256 in config/vrs096-approved.json, exact model/reference/classifier and CPU backend binding, explicit frozen thresholds no looser than legacy .12/.005, declared distinct train/holdout groups and two or more reviewer identifiers, unique calibration rows, accepted count/error gate per convention, geometry certificate for exact manuscript hash/page/region/crop hash/box. Every loaded convention must have its own calibrated model. Auto acceptance only for individually certified geometry and threshold passing scores. No automatic creation of approval; declaration and local owner approval do not prove actual scientific independence, provenance authenticity or statistical generalization. Current test approval is entirely synthetic and not valid for the real manuscript. No genuine calibration data used. Revoking approval fails closed.
- Persistent append-only review revisions in an additive local SQLite table; original classifications and queue snapshots unchanged. Per-convention mapped/absent/unknown disposition, false positive, compound, deferred. Every loaded convention receives an explicit disposition for a glyph decision. Compound/deferred are outstanding until revised; no new box geometry or split/merge/resegmentation implementation in this increment. Candidate ID, run, immutable queue hash, revision compare-and-swap, local reviewer identity and label membership checked. Trusted local CLI submission, not a multiuser authentication system. Conflict rejected, identical retry idempotent when no active owner. Partial decisions stay parked; final resolved dependency transitions only BLOCKED run to READY; paused run requires explicit resume, cancelled run cannot be mutated. Scheduler-wide lock not acquired for review submission; SQLite transactions protect competing revisions. Large queue validation and repeated source rehashing may be expensive, not profiled at manuscript scale. Raw model predictions not included in routine decision list, no blind ground-truth inference.
- Actual comparison via existing alignment.load_source/compare for pinned IVTFF transcriptions. Mapping must be explicit for source manuscript and each transcription, bind exact crop bytes and complete locus/subtype/mapper; no inferred locus/text matching, duplicate confirmed locus rejected. Unconfirmed regions stay UNRESOLVED; unknown/absent contribute no asserted mapping, false positives excluded with count, unresolved compound/deferred blocks review. Empty page handled without manufactured match. Missing mapping is BLOCKED, not an all-loci comparison. Reports and observation artifacts private under workspace and index hash-bound. No comparison or correction promotes scientific status, model or training data. G8 publication remains later.
- New runtime vrs_runtime.py extends existing local scheduler with real recognition and review paths. It runs fixed locally registered scopes independently; no remote job intake, experiment planning or arbitrary execution. CPU only; auto resolves to CPU and explicit CUDA remains unsupported in this runtime. Region and segmentation algorithms still proposal algorithms, not independently validated script/non-script detection. Existing old run identities are retained, not automatically migrated (including service identity affected by V2 queue source edit); use old code for previous pinned runs or explicitly register new scope with new nonce. No forced old workspace deletion. CLI controlled local foreground/headless service, not a Windows service.

## Local configuration contract

Use the existing VRS-092 fixed-scope manifest, with relative {path,sha256} references.
- references points to {schema:1,inventories:[{alphabet:REF}, ...]}. Each alphabet contains convention and labels in existing glyphs.inventory format.
- model points to {schema:1,models:[{convention,model:REF,report:REF}, ...]} for existing prototype model and matching report. At least one model; missing convention causes abstention, not cross-convention mapping.
- recognition_policy points to {schema:1,approval:null,mapping:null} for the safe initial path. Optional approval/mapping are pinned refs. Approval requires explicit local allowlist; never generate trust from a manifest. See vrs_recognition.py for exact approval/calibration/geometry schema and test fixture only for structural examples. Real approval must originate from independent authorized evidence, not the test fixture.
- Optional mapping file {schema:1,manuscript_sha256,sources:{SOURCE_SHA:{"PAGE:REGION_ID":{crop_sha256,locus,subtype,mapper}}}}. Each mapping entry is a declaration of confirmed complete physical locus by an authorized curator. Unmapped regions remain unresolved. Missing whole mapping blocks alignment. Source version/format must be supported by existing strict IVTFF parser.
- Decision {schema:1,run_id,queue_sha256,candidate_id,expected_revision,reviewer,kind,mappings}. kind glyph uses mappings keyed by every inventory convention, value {state: mapped|absent|unknown,label: code|null}. false_positive/compound/deferred use empty mappings. Source hashes, candidate identity and original box never overwritten.

Commands from worker/ with existing compute environment:
`python vrs_runtime.py ROOT register config/run.json`
`python vrs_runtime.py ROOT watch --plan config/local-plan.json --interval 5`
`python vrs_runtime.py ROOT queue RUN_ID --limit 100`
`python vrs_runtime.py ROOT decide config/decision.json`
`python vrs_runtime.py ROOT once`, `list`, `status RUN_ID`, `pause RUN_ID`, `resume RUN_ID`, `cancel RUN_ID`, `recover RUN_ID GENERATION --confirm-stopped`.
Recovery requires previous process actually stopped. Use this runtime for new 0.9.6 runs, not older CLI or direct ledger mutation. GUI integration in 0.10.0/0.10.1; portable bootstrap in 0.13.0.
