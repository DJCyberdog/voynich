Run locally on an offline, stopped disposable copy: `python vrs_rc_preflight.py PATH_TO_WORKSPACE --current-worker 64_HEX_DIGEST`. The optional identity is an explicit comparison, not proof of executable identity. No compute dependency. Output contains aggregate counts and digests, not reviewer names, tokens, file paths or glyphs. No database or artifacts are rewritten. Audit checks direct ledger-bound hashes, queue and decision revisions, history/outbox reference envelopes, SQLite integrity and ownership. This is not exhaustive transitive artifact validation or a filesystem-wide snapshot. External concurrent file modification cannot be excluded by this tool; use a stopped workspace and separately verified backup. Preflight PASS is not migration/rollback acceptance and cannot authorize historical run resume. No arbitrary schema conversion.

## Private app snapshot and rollback preparation

`python vrs_rc_snapshot.py snapshot APP_ROOT NEW_BACKUP_DIR --private-local` creates an exact byte inventory of a stopped disposable app (all files and empty directories, except the three shared transient lock files). Keep the emitted SHA-256 separately. `verify BACKUP --approve SHA256 --private-local` checks exact payload and ledger; `restore BACKUP NEW_RESTORE_DIR --approve SHA256 --private-local` materializes a fresh app under NEW_RESTORE_DIR/app, without overwriting the source or any existing destination. A restored portable environment needs offline Repair before use. Stop GUI, workers, publisher and all unmanaged writers first; shared locks fence normal managed execution, not hostile concurrent writers. Snapshots contain private data and may include encrypted credentials; never publish, do not share, use a private local disk with restrictive ACLs. DPAPI is still bound to the Windows user/machine; no credential portability promised. Byte inventory is not an ACL/ADS/timestamp/OS snapshot. Links, hardlinks, Git checkouts, special files, sidecars, active ownership, tampering and case collisions are refused. Limits 64 GiB / 250,000 entries. No data rewriting or source identity migration; exact rollback is restoration into a new path. Real old-version migration, portable repair and complete release qualification remain open. Tests pending.
