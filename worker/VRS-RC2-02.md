# RC2-02 — conservative segmentation and occurrence deduplication

Status: IMPLEMENTED / qualification pending. No scientific, owner or release acceptance.

The RC1 vertical projection was designed for a single line but is applied to overlapping, multiscale windows. It can combine unrelated rows and create repeated proposals. The RC2 page-stage adapter keeps the exact legacy projection as a hypothesis (method bit 1). Where completely white horizontal row gaps of at least three raster pixels separate bands, it additionally emits per-band vertical projections (bit 2). A coincident method-1/2 box is one raw hypothesis with both bits. A band is not a verified text line. Legacy spanning, clipped, compound and partial boxes are never silently deleted by this change.

Per page, hash exact RGB bytes of every crop-relative hypothesis, transform its rectangle to original full-page pixel coordinates, and group only equal page position, bounds and pixel hash. Equal-looking glyphs elsewhere, unequal bounds, touching/overlapping but non-identical candidates and same-position pixel conflicts are retained separately. Representative ranking: greatest minimum margin to crop edge, then larger crop area, then deterministic region ID/box. Preserve all original hypotheses with their crop IDs, boxes, method and pixel hashes, plus exact aliases pointing to their representatives and complete counts. Every raw hypothesis maps to exactly one retained representative or alias. No similarity threshold, transitive clustering, automatic propagation, training, false-positive label or scientific acceptance. Edge-touching counts are diagnostic only. Geometry replay validates aliases and denominator before resume and downstream use; hash-bound crop artifacts and page receipts preserve provenance. The existing occurrence-ID contract continues to bind the retained candidate to its crop, relative box and run. Old committed evidence stays readable; new worker identity fences incompatible checkpoints. Historical glyphs.boxes/feature code remains unchanged so legacy feature/model provenance is not silently altered.

Both Coordinator and actual Runtime/Service use the same implementation; new resumable segmentation checkpoints require the new lineage. The exception outcome adapter validates any RC2 lineage it reads and admits 214 pages only for the exact Yale source. Explicit per-page 100000 raw-hypothesis guard and existing page-artifact quota fail closed; no truncation or target queue-size tuning. This is bounded per-page working memory, not a measured hard cap. Native performance optimization remains RC2-05/12.

## Qualification plan

Synthetic independent geometry controls (known coordinates defined before segmentation): repeat-looking marks at distinct positions, multi-row boxes, exact duplicate, clipped/partially overlapping occurrence, same-coordinate differing pixels, blank page, deterministic input-order-independent selection, tamper, stop and budget guards. Actual Runtime route controls for durable receipts, with existing synthetic surface/glyph regression. Full private Yale audit compares all legacy and retained hypotheses, exact aliases and conflict counts by page without publication of crops. Count changes are engineering measures, not glyph-count estimates, recall or scientific precision. Independent real-source script/compound/glyph labels are still missing; do not report model quality or eliminate non-script ink without a validated policy. All owner-source, release and scientific gates remain unchanged. No intermediate owner patch.
