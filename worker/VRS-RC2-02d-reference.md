Python 3.13, existing NumPy/Pillow/PyMuPDF plus local SciPy and scikit-learn 1.8.0; no new portable runtime requirements. No output model, no private training rows in Git. 22 features: native crop dimensions/area, normalized distance from scan edge, ensemble votes/density, connected components, gray/channel statistics and flag fractions. Same frozen six-method votes and context margin as previous experiment. Binary label handwriting vs non-script/blank. 158 of 160 enriched algorithm cases (66 handwriting, 92 non-script/blank; mixed and uncertain excluded). 20 random windows computed but excluded from training/evaluation; 20 modern wrapper controls excluded. Five stratified group folds using number from source PDF folio captions (recto/verso same group, non-folio captions pooled as other; 70 groups total, no fold group overlap). This grouping is an approximation, not verified physical leaf identities for all foldouts. Logistic regression C=1 with fold-local StandardScaler and 300-tree random forest min_samples_leaf=4, sqrt features, seed 271126. Every reported score out of fold. Dataset already used for feature/method development, hence no untouched independent holdout. Scores not calibrated probabilities. Thresholds illustrative, no production threshold selected.
